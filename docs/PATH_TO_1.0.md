# Path to 1.0

The current pre-1.0 milestones and open work live in
[`ROADMAP.md`](../ROADMAP.md). Release acceptance requires:

- a stable documented public API with an automated surface check;
- blocking host, supply-chain, and real-GPU gates;
- standard SQL semantics for every claimed shape;
- explicit `Gpu`, `Host`, or `Hybrid` execution placement;
- reproducible performance and capacity evidence; and
- no unresolved release-blocking item in [`LIMITATIONS.md`](LIMITATIONS.md).

The original milestone essay was drafted against version 0.3 and is preserved
only as engineering history in
[`internal/history/PATH_TO_1.0-0.3-baseline.md`](internal/history/PATH_TO_1.0-0.3-baseline.md).
Its “today” columns are not current project state.
